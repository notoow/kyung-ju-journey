# 경주 여행 템플릿

개인 여행 기록이나 계정 연결 없이 재사용하는 정적 여행 사이트입니다.

## 빠른 시작

저장소의 **Use this template**로 복사한 뒤 `python -m http.server 8000`을 실행하고 http://localhost:8000 을 엽니다. Node나 빌드 과정은 실행에 필요하지 않습니다.

- `places-extra.js`: 공개 관광지·음식점, 주소, 지도 및 전화 링크
- `index.html`: 제목·설명·3일 예시 일정
- `app.js`: 지도와 예시 동선, 일정 탭
- `explore-ui.js`: 목록·필터·모바일 접기·현재부터 3일 날씨
- `styles.css`: 색상과 반응형 디자인

개인 이름, 생일, 실제 예약·숙소·픽업 일정은 포함하지 않습니다. 계정·댓글·응원 집계·분석 도구가 없으며 사용자 입력을 서버에 저장하지 않습니다. 날씨는 버튼을 눌러 조회합니다. 지도 타일과 폰트는 외부 CDN을 이용하므로 해당 제공자에게 일반적인 접속 정보가 전달될 수 있습니다.

## 배포

GitHub Settings → Pages → Source를 GitHub Actions로 설정하고 main에 push합니다. `.github/workflows/deploy.yml`이 정적 사이트를 배포합니다. 복제 후 footer의 저장소 링크를 자신의 주소로 변경하세요.

## 라이선스와 자료

직접 작성한 코드와 SVG는 MIT License입니다. 외부 패키지는 각자의 라이선스를 따릅니다(Leaflet: BSD-2-Clause, Pretendard: SIL OFL). 지도는 OpenStreetMap 기여자 표시를 유지하세요. 외부 서비스, 상표, 연결된 페이지 및 사진에 MIT 라이선스가 적용되는 것은 아닙니다.

재배포 권한을 확인하지 못한 사진은 포함하지 않았습니다. 사진을 추가할 때는 직접 촬영했거나 재배포 허가가 있는 사진을 사용하고 해당 라이선스를 표시하세요. 공개 장소 정보도 방문 전에 확인하세요.

## 개인정보 정리 후 작업

이 저장소는 개인정보가 포함된 이전 이력을 제거한 새 단일 루트 이력으로 전환되었습니다. 이전 clone의 브랜치를 merge하거나 push하지 말고 새로 clone하세요. 외부 복사본과 검색 캐시, 플랫폼 내부 보존 데이터는 이 저장소만으로 삭제할 수 없습니다.

## 구현 기록 (개인정보 제외)

- Leaflet 지도에 공개 장소를 연결하고 카카오맵·네이버지도 및 매장 전화 링크를 제공했습니다.
- 일정 탭은 외부 지도 라이브러리 로딩이 실패해도 동작하도록 분리했습니다.
- 작은 화면에서 버튼이 잘리거나 줄바꿈되는 문제를 점검하고 모바일 목록·카드 접기를 추가했습니다.
- 날씨와 일출·일몰을 표시하고 예보가 없거나 조회가 실패하면 상태를 명확히 표시합니다.
- 이전 버전의 공유 메시지·응원 기능은 인증과 서버 규칙을 이용했지만 공개 템플릿에서는 제거했습니다. 운영 계정이나 사용자 자료 없이 화면·지도 기능만 재사용합니다.
- 공개 전 개인 행사 콘텐츠·실제 일정·계정 연결·외부 사진을 제거하고, 과거 배포 이력과 Git 이력을 정리했습니다.
- 자동 검증은 일정 탭, 공개 장소 데이터, 메시지 연결 제거, 불완전한 예보 거부를 확인합니다.

이 기록은 기술적인 작업 내용을 보존하기 위한 요약이며 실제 사용자 메시지·접속자 식별자·예약 내용은 포함하지 않습니다.
