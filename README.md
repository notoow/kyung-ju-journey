# 경주 가족 여행

2026년 10월 24일~26일 가족 여행 안내 정적 웹사이트입니다.

## 실행

`python -m http.server 8000` 실행 후 http://localhost:8000 을 엽니다. 별도 빌드가 없습니다.

## 데이터와 사진

- 가족 명의 기본 축하 메시지 및 임의 소개문을 삭제했습니다.
- 이전 `kyungju_journey_messages` 저장소는 로드 시 제거합니다. 이후 작성 메시지는 `kyungju_journey_messages_v2`에 저장하며 다른 기기와 공유되지 않습니다.
- 출처 없는 별점·메뉴 가격과 단정적인 이동 시간을 삭제했습니다.
- 관광 사진은 경주시·국가유산청, 식당 사진은 해당 매장의 관광정보·메뉴판닷컴·방문 후기에서 확인했습니다. 숙소 사진은 피치바이피치 소개 자료입니다.
- 사진 출처와 확인일은 `assets/image-sources.json` 및 각 카드에 표시했습니다. 사진 권리는 원 출처에 있습니다.
- 케이크 디자인과 사진은 표시하지 않습니다. 프라메리는 픽업 장소·시각만 안내합니다.
- 방문·픽업 시각은 계획이며 예약 완료를 증명하지 않습니다. 운영시간·가격·메뉴는 방문 전에 매장에 확인하세요.
- 대표 관광지 25곳, 식당·픽업 장소 19곳, 숙소 1곳을 표시합니다. 식당·숙소 도로명 주소 좌표는 Esri World Geocoding Service로 확인했고 `assets/location-sources.json`에 기록했습니다. 관광지 핀은 장소 일대이며 주차장·출입구 길찾기는 카카오맵·네이버지도를 이용하세요.

## 검증

`node --check app.js`

`node --test tests/*.test.cjs`

## 일정과 탐색

- 첫날 점심 수리뫼, 둘째 날 점심 복길. 첫날 송대말등대 산책 후 회 포장, 저녁 후 월정교 야경.
- 관광지는 권역별, 식당은 메뉴 종류별 필터를 제공합니다. 복길·함양집 테이블링, 향화정 캐치테이블 매장 링크를 연결합니다. 원격 대기와 시간 지정 예약을 구분합니다. 실제 예약은 수행하지 않습니다.
- `places-extra.js`는 추가 장소 데이터, `explore-ui.js`는 카드·필터·날씨 화면입니다. `explore.js`에는 사진 출처와 Open-Meteo 저장 예보가 들어 있습니다.
- 날씨는 경주 시내 좌표, Asia/Seoul 기준 10/24–26 예보를 새로 조회합니다. 실패하면 확인 시각을 표시한 저장 예보를 보여 줍니다. 예보는 변동될 수 있으며 날짜가 지난 뒤에는 저장 예보로만 열람될 수 있습니다.
- 외부 지도 로딩과 기본 일정 탭 초기화를 분리했습니다. 아이콘·파비콘은 로컬 SVG입니다.
