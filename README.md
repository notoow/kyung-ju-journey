# 경주 가족 여행

2026년 10월 24일~26일 가족 여행 안내 정적 웹사이트입니다.

## 실행

`python -m http.server 8000` 실행 후 http://localhost:8000 을 엽니다. 별도 빌드가 없습니다.

## 데이터와 사진

- 가족 명의 기본 축하 메시지 및 임의 소개문을 삭제했습니다.
- 축하글과 축하 횟수는 Firebase `mini-sites-hub`의 `sites/kyungju-2026`에서 기기 간 공유합니다. 이전 브라우저 전용 글은 자동 공개하거나 삭제하지 않습니다.
- 출처 없는 별점·메뉴 가격과 단정적인 이동 시간을 삭제했습니다.
- 관광 사진은 경주시·국가유산청, 식당 사진은 해당 매장의 관광정보·메뉴판닷컴·방문 후기에서 확인했습니다. 숙소 사진은 피치바이피치 소개 자료입니다.
- 사진 출처와 확인일은 `assets/image-sources.json` 및 각 카드에 표시했습니다. 사진 권리는 원 출처에 있습니다.
- 케이크 디자인과 사진은 표시하지 않습니다. 프라메리는 픽업 장소·시각만 안내합니다.
- 방문·픽업 시각은 계획이며 예약 완료를 증명하지 않습니다. 운영시간·가격·메뉴는 방문 전에 매장에 확인하세요.
- 대표 관광지 25곳, 식당·픽업 장소 19곳, 숙소 1곳을 표시합니다. 식당·숙소 도로명 주소 좌표는 Esri World Geocoding Service로 확인했고 `assets/location-sources.json`에 기록했습니다. 관광지 핀은 장소 일대이며 주차장·출입구 길찾기는 카카오맵·네이버지도를 이용하세요.

## 공용 댓글 백엔드

- `community-config.js`는 공개용 Firebase 설정이며 비밀 키가 아닙니다. `community.js`가 기존 카드 디자인에 글 작성·조회·비밀번호 삭제와 축하 버튼을 연결합니다.
- 첫 화면에 `🎉 축하해요` 버튼 하나를 표시합니다. 누적 횟수 제한 없이 누를 때마다 즉시 숫자와 0.65초 말풍선 효과가 반응합니다. `applause-queue.mjs`가 약 0.9초 동안 연타를 모아 요청당 최대 60회씩 순차 저장하며, 저장 중에도 새 클릭을 받습니다. 서버 규칙은 500ms 간격, 본인 문서, 증가량 1~60을 강제합니다. 총합은 문서 수 + `extra` 합계로 계산하여 기존 좋아요도 보존합니다. 새로고침할 때 전체 횟수를 갱신하며 실시간 구독은 사용하지 않습니다.
- 저장 대기 중에는 상태를 표시하고, 저장 실패 시 미저장 숫자를 되돌립니다. 페이지가 숨겨질 때 저장을 시도하지만 브라우저를 즉시 닫으면 아직 전송하지 못한 클릭은 유실될 수 있습니다. 축하 집계는 실제 인원 수나 부정 방지 투표로 사용하지 않습니다.
- Spark 무료 요금제를 유지하며 결제 계정을 연결하지 않습니다. Cloud Functions, Storage, 유료 백업은 사용하지 않습니다. 프로젝트와 글에 종료일을 설정하지 않았습니다. 서비스의 무료 정책과 할당량은 별도로 적용됩니다.
- 글마다 작성자가 숫자 4~6자리 삭제 번호를 정합니다. 6자리를 권장합니다. 번호나 검증용 해시는 공개 문서에 저장하지 않습니다. 글별 임의 식별자와 번호로 만든 자격 증명을 Firebase Authentication에서 검증합니다. 삭제 후 해당 글의 임시 계정도 정리합니다.
- 봇 검증: App Check + 도메인이 제한된 reCAPTCHA Enterprise Essentials. 서버 규칙: 본인 글만 삭제, 임의 수정 금지, 글자 수 검증, 사이트 전체 10초 간격·24시간 100글 제한, 최신 30개씩 조회.
- 짧은 번호 추측, 새 브라우저를 이용한 축하 중복, 무료 한도를 소진시키는 공격을 완전히 막지는 못합니다. 공개 축하글용이며 민감한 자료를 보관하면 안 됩니다. 비밀번호를 잊은 글은 Firebase 콘솔에서 관리자가 삭제해야 합니다.
- 운영 규칙·통합 테스트·재사용 안내는 같은 작업 폴더의 `../mini-sites-hub/`에 있습니다. 로컬 미리보기는 그 폴더의 안내를 따르세요. 운영 도메인 외에서는 App Check가 연결을 차단하는 것이 정상입니다.

## 일정과 탐색

- 첫날 점심 수리뫼, 둘째 날 점심 복길. 첫날 송대말등대 산책 후 회 포장, 저녁 후 월정교 야경.
- 관광지는 권역별, 식당은 메뉴 종류별 필터를 제공합니다. 복길·함양집 테이블링, 향화정 캐치테이블 매장 링크를 연결합니다. 원격 대기와 시간 지정 예약을 구분합니다. 실제 예약은 수행하지 않습니다.
- `places-extra.js`는 추가 장소 데이터, `explore-ui.js`는 카드·필터·날씨 화면입니다. `explore.js`에는 사진 출처와 Open-Meteo 저장 예보가 들어 있습니다.
- 날씨는 경주 시내 좌표, Asia/Seoul 기준 10/24–26 예보를 새로 조회합니다. 실패하면 확인 시각을 표시한 저장 예보를 보여 줍니다. 예보는 변동될 수 있으며 날짜가 지난 뒤에는 저장 예보로만 열람될 수 있습니다.
- 외부 지도 로딩과 기본 일정 탭 초기화를 분리했습니다. 아이콘·파비콘은 로컬 SVG입니다.
