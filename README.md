- 🌸 **정화영** (엄마) : 온화한 미소와 따뜻한 사랑으로 가족을 품어주는 천사
- 👰 **박정은** (딸 & 예비 신부) : 아빠의 보물이자 사랑스러운 맏딸
- 🤵 **우탄** (예비 사위 / 예비 신랑) & **박정훈** : 든든하고 유쾌한 가족 케미메이커

## 🗺️ 포함된 명소 및 맛집
### 🏛️ 경주 대표 관광지
- **불국사:** 유네스코 세계문화유산, 다보탑과 석가탑 (경주시 불국로 385)
- **동궁과 월지:** 환상적인 야경과 연못의 반영 (경주시 원화로 102)
- **대릉원:** 거대한 신라 고분군과 천마총, 목련 포토존 (경주시 황남동 31-1)
- **황리단길:** 감성 카페와 맛집, 전통과 현대가 어우러진 거리 (경주시 황남동 포석로 일대)

### 🍱 소문난 대표 맛집
- **향화정:** 꼬막무침비빔밥 & 육회물회 & 해물파전 (경주시 사정로57번길 17)
- **함양집:** 4대째 전통 살얼음 한우물회 & 육회비빔밥 (경주시 북군1길 10-1)
- **경주원조콩국:** 따뜻하고 진한 전통 콩국과 찹쌀 도너츠 (경주시 첨성로 113)

## ✨ 웹사이트 주요 기능
1. **인터랙티브 전체 지도 (Leaflet.js)**: 한 장의 지도 위에 숙소, 관광지, 맛집을 카테고리별 마커로 표시하고, 클릭 시 상세 정보 및 카카오맵/네이버 지도 길찾기 연동
2. **환갑 축하 컨페티 효과**: 환갑 축하 버튼을 누르면 화면 가득 축하 꽃가루 폭죽 발사!
3. **2박 3일 상세 일정표**: 10/24 생신 파티부터 10/26 귀가까지 일자별 추천 동선
4. **가족 롤링페이퍼 (축하 메시지)**: 가족들이 현장에서 실시간으로 축하 한마디를 남기고 공유
5. **모바일 최적화 반응형 UI**: 이동 중 스마트폰으로 편하게 길찾기 및 정보 확인 가능
6. **카카오톡 공유 & 링크 복사**: 온 가족 단톡방에 원클릭으로 웹사이트 공유

## 🚀 GitHub Pages 배포 가이드
이 저장소는 GitHub Pages를 통해 무료로 웹 호스팅할 수 있습니다.

### 방법 1 (간편 설정):
1. GitHub 저장소(`https://github.com/notoow/kyung-ju-journey`)로 이동
2. 상단 탭 **Settings** > 좌측 메뉴 **Pages** 클릭
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정
4. Branch를 `main` / `/(root)`로 선택 후 **Save** 버튼 클릭
5. 1~2분 후 `https://notoow.github.io/kyung-ju-journey/` 링크로 전세계 어디서든 접속 가능!
